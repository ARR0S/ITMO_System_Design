# AI-система автоматизации тикетов поддержки

Репозиторий содержит архитектурный дизайн и минимальный PoC системы
для классификации, маршрутизации и безопасной автоматизации тикетов
крупного онлайн-сервиса.

Целевое решение разделяет быстрый контур классификации и маршрутизации
и медленный контур retrieval/LLM. Высокорисковые и low-confidence
обращения передаются оператору, а отказ LLM не останавливает основной
процесс обработки тикетов.

Планируемый PoC продемонстрирует:

1. безопасный happy path с retrieval и mock LLM;
2. high-risk path с передачей оператору;
3. degraded path при недоступности LLM.

На текущем этапе зафиксированы требования, архитектура, ML-дизайн,
мониторинг и эксплуатационные риски. Реализация PoC будет добавлена
следующими логическими коммитами.
